# 🚀 Быстрый запуск проекта

Для удобства проверки мы упаковали весь проект в Docker. Запуск займет не более пары минут.

## 🛠️ Шаг 1. Получение Groq API Ключа

Наш проект использует модели через API Groq. Вам понадобится бесплатный ключ:
1. Перейдите на сайт [Groq Console](https://console.groq.com/keys).
2. Авторизуйтесь (через Google или GitHub) и нажмите **"Create API Key"**.
3. Скопируйте созданный ключ.

---

## 📝 Шаг 2. Настройка окружения (`.env`)

В корне проекта создайте файл `.env` (или переименуйте `.env.example`, если он есть) и добавьте туда ваш ключ:

```env
GROQ_API_KEY=ваш_ключ_от_groq_сюда
```

---

## 🐳 Шаг 3. Запуск через Docker

Убедитесь, что у вас запущен Docker Desktop, после чего выполните в терминале команду для сборки и запуска проекта в фоновом режиме:

```bash
docker compose up -d --build
```

> **Примечание:** Если вы используете старую версию Docker, команда может выглядеть как `docker-compose up -d --build` (через дефис).

После того как контейнеры поднимутся, проект будет доступен по адресу:  
🔗 **http://localhost:3000** *(замени порт 3000 на свой)*

---

## 🛑 Остановка проекта

Чтобы остановить контейнеры и освободить порты, выполните:
```bash
docker compose down
```
