# 🚀 Быстрый запуск проекта

Для удобства проверки мы упаковали весь проект в Docker. Запуск займет не более пары минут.

## 🛠️ Шаг 1. Получение Groq API Ключа

Наш проект использует модели через API Groq. Вам понадобится бесплатный ключ:
1. Перейдите на сайт [Groq Console](https://console.groq.com/keys).
2. Авторизуйтесь (через Google или GitHub) и нажмите **"Create API Key"**.
3. Скопируйте созданный ключ.

---
